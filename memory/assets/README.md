# 写作素材库

> 这些是**结构模板**，不是任何单位的正式范文；示例段落全部虚构，只演示骨架。
> 用语未经你确认前，默认按通用规范写，不硬套你单位的习惯说法。

| 文件 | 用途 |
| --- | --- |
| `00-公文通用规范.md` | 要素顺序、层次序数、用语表、五条禁忌、自查清单 |
| `01-请示.md` | 一文一事、金额测算、常见退回原因 |
| `02-报告.md` | 只汇报不夹请示、数据写法 |
| `03-通知.md` | 印发/部署/告知三类骨架 |
| `04-函.md` | 平级商洽口吻与四类结语 |
| `05-会议纪要.md` | 议定事项 + 落实分工表 |
| `10-课纲与课件结构.md` | 课纲五段式、时长配比、课件页规则 |

补充方式：把你认可的真范文贴给我，我在对应骨架里加一节「用户版用语」，注明来源与日期，不动模板主体。
