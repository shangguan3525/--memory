# 商业授课：课纲与课件结构

## 一、课纲五段式

1. **受众与痛点**：谁来听、他们的岗位、最近一个真实卡点（一句原话最好）。
2. **学习目标**：3 条，动词可验收——"能写出/能算出/能判断"，不写"了解""认识"。
3. **模块表**：每模块写清"讲师讲什么 + 学员做什么"。
4. **案例**：每模块 1 个真实场景 + 1 个失败反例。
5. **交付物**：模板、清单、工具表——学员带走的东西。

## 二、时长配比（默认值，按需调）

| 环节 | 占比 | 作用 |
| --- | --- | --- |
| 导入（痛点/悬念） | 10% | 建立"这跟我有关" |
| 主体（讲 + 演） | 60% | 每 12—15 分钟一次互动 |
| 演练（学员做） | 25% | 必须产出可检查的东西 |
| 收口（带走清单） | 5% | 3 条要点 + 1 个行动 |

**校验规则**：如果某个模块只有"讲师讲什么"，没有"学员做什么"，这个模块不成立。

## 三、课件页结构

- **一页一观点**，标题就写结论（"三成返工来自需求描述不清"，不写"需求分析概述"）。
- 数据页：1 张图 + 1 句结论 + 来源标注（右下角小字）。
- 流程页：不超过 7 步，超过就拆两页。
- 练习页：紧跟一页标准答案，否则学员不知道自己错在哪。
- 收尾页：3 条带走清单 + 1 个课后动作（给转化留接口）。

## 四、商业课特有

转化设计放在最后 5 分钟：一个可立刻用的模板 + 一个下一步动作（复训/诊断/工具包）。
